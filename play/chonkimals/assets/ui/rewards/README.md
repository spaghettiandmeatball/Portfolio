# Care Package reward art

Drop a **square, transparent PNG (~512 px)** here named `<id>.png` and it replaces the generated
placeholder automatically — no code change. The full list of possible rewards (the inventory sheet)
lives in `src/care-package/rewards.ts`: edit names, rarities, blurbs or add rows there.

Troop gear (pennant / tent) shows a generated pennant / tent in its colours, and is also sold in
the Shop's Troop tab when it has a `shopPrice`. Characters already show their chonk portrait (`assets/ui/chonks/<chonk>.png`); a file here overrides it.
